## ⚠️ Unverified specs — fill before publishing

The storefront returns 403 to automated requests, so these could **not** be
confirmed. Every one of them appears in the scripts as a bracketed placeholder.
Replace them with real values — do not ship the scripts with guesses in place.

- `[PRICE]` — retail price
- `[FABRIC]` — fibre content (e.g. 100% combed ringspun cotton)
- `[GSM]` — fabric weight
- `[SIZES]` — size run
- `[FIT]` — brand's stated fit (regular / relaxed / oversized)
- `[SHRINK]` — pre-shrunk or not
- `[SHIP_TIME]` — dispatch window
- `[CREATOR_SIZE]` — the size the creator is actually wearing
- `[CREATOR_HEIGHT]` — creator height, for fit context

## Before you publish

1. **The creator must actually own and wear the tee.** These scripts are a
   performance brief, not a review to post under a fabricated identity.
2. **Disclose the relationship.** If the creator was paid or gifted, the video
   needs a clear, unmissable disclosure — `#ad` or `#gifted` in the caption
   *and* spoken or on-screen in the first few seconds. FTC rules treat a buried
   hashtag as no disclosure at all.
3. **Only keep claims that survive fact-check.** Anything still in brackets is
   an unverified claim. Cut it or confirm it.
